# Thinker Chess — Landing Page

Landing page do produto **Thinker Chess**, construída com HTML, CSS e JavaScript puro (Vanilla JS).

## Estrutura

- `index.html` — Esqueleto base da página
- `style.css` — Variáveis de design, reset, tipografia e classes utilitárias
- `main.js` — Renderização de seções, componentes, animações e interações

## Como usar

Abra o arquivo `index.html` em um navegador.

## Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Google Fonts (Playfair Display + Inter)
